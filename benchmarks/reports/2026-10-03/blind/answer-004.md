4. **Source preview prefers the local filesystem.** Once a graph record exists, it reads the recorded file beginning at the indexed start line. Defaults are 80 lines/4,000 characters; maximums are 400/16,000. `full_source_preview=True` also respects the indexed end line, within those caps. A successful local preview returns immediately. 5. **Postgres supplies the source fallback.** If local source is unavailable, empty, or raises an exception, it selects one `codebase_embeddings` chunk for the same project/file. Ordering prefers a matching `declared_symbols` entry, then a definition chunk, then proximity to the indexed start line, then chunk index. This is SQL selection, not vector search. It applies the character cap, but does **not** apply the line cap or reconstruct the full symbol span. If Postgres fails, its exception is swallowed and graph context is returned without source.
