# Native benchmark measurement notes

Revision: b05363c4b43df110f749a0a238fc0589bd76a49f (verified before cases).

Native-only source inspection pilot, 15 sequential cases in one agent session; shared context and filesystem caches are not reset. elapsed_seconds is actual Date.now wall time from first case search to recorded answer, including reasoning and orchestration. Setup protocol reads were not timed and setup_seconds=0 means no indexing/setup was performed, not zero protocol overhead. Per-case token estimates are ceil((captured tool output characters + command characters)/4) input and ceil(answer characters/4) output; they are NOT total model/billed tokens and exclude inherited context, repeated context, reasoning and orchestration. No per-case model telemetry API was available. Tool calls count executed native inspection shell invocations including failed searches. files_opened counts unique existing source files whose content appeared in command output, including exact search excerpts; failed paths and protocol files excluded. native_fallback_calls=0 because native is the assigned baseline, not a fallback. Correctness is source-based self-assessment, not independent grading. See native-transcript.json for full command/output and timestamps.

All 15 answers were independently investigated using shell exact search and file reads. No GraphRAG/MCP investigation tools, other agents' answers, or other benchmark results were read. Initial protocol reads: AGENTS.md, cases JSON, result schema; revision verification used git rev-parse HEAD. Those three initial shell invocations are excluded from case counts. No implementation files were changed.

Summed case end-to-end wall time: 311.812 seconds. Earliest case start: 2026-09-06T16:38:29.919Z. Last case finish: 2026-09-06T16:43:41.753Z. This excludes report serialization/validation and unmeasured initial protocol overhead. The shell tool's wall_time_seconds fields are preserved but report near-microsecond values; they should not be interpreted as complete tool latency. Native end-to-end time is not directly comparable to MCP tool-latency-only time.

Input/output integer token fields are transparent character-based proxies, not actual telemetry. No tokenizer call or hidden chain-of-thought was included. This pilot cannot establish a measured token-cost advantage. Accuracy flags are provisional honest self-assessments of the delivered bounded claims; several cases explicitly identify implementation limitations (dependency text manifests ignored by Python-only fingerprint collection, graph required for symbol lookup, cross-project call target name ambiguity).

The agent retained context across cases, so earlier reads could inform later questions (notably startup/session and memory configuration/resilience); this is not a cold per-case experiment. Files-opened means distinct files represented in source output within that case, not OS open syscall counts. Exact searches can return partial context and failed guessed paths are included in tool call counts.
