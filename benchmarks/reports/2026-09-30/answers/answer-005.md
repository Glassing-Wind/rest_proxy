Question: Find the implementation of symbol-context lookup and explain its graph and source fallbacks.

The implementation is **`get_symbol_context()`**, registered in [core.py:1065](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/core.py:1065). Its flow is **graph lookup → candidate selection → optional local source → stored source fallback**.

1. **Graph lookup is required.** It obtains a Neo4j driver and executes `SYMBOL_CONTEXT_CYPHER`. The query matches the workspace’s symbol by exact `name` or `qualified_name`, with optional file-path and signature filters. It collects the containing file, incoming/outgoing `CALLS` **and** `CALLS_INFERRED` edges, and separate external-symbol calls. Results are capped at 12 candidates and 10 entries per relationship list. Inferred edges are queried together with direct edges, rather than retried as a separate fallback. [core.py:1092](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/core.py:1092), [symbol_graph.py:35](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/symbol_graph.py:35)

2. **Candidate selection uses heuristics.** Candidates are ranked and deduplicated using file/signature matches, qualified names, file roles, symbol kinds, and connectivity. Certain ambiguous short names return a candidate list asking for specificity; otherwise the top candidate wins. No match returns “Run index_workspace() first”—it does not search source for an unindexed definition. [symbol_graph.py:321](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/symbol_graph.py:321), [symbol_graph.py:381](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/symbol_graph.py:381), [symbol_graph.py:453](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/symbol_graph.py:453), [core.py:1120](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/core.py:1120)

3. **Missing graph edges do not trigger automatic source-based call discovery.** Formatting filters incompatible-language relationships and suppresses duplicate/self-alias callers. For Python symbols with neither displayed callers nor callees, it suggests `find_references` or `search_codebase`; those tools are not invoked. Graph failure also has no source-only recovery: an unavailable driver raises, and the outer handler returns an error string. [symbol_graph.py:783](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/symbol_graph.py:783), [symbol_graph.py:992](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/symbol_graph.py:992), [graph_bootstrap.py:423](/Users/michaelmarler/Projects/rest_proxy/graph_bootstrap.py:423), [core.py:1232](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/core.py:1232)

4. **Source preview prefers local files.** With previews enabled, an existing `workspace_id` path allows reading the selected file from its indexed start line. Defaults are 80 lines/4,000 characters, capped at 400/16,000. `full_source_preview` additionally uses the indexed end line, within those caps. A nonempty snippet returns immediately; missing files, empty snippets, or read errors fall through. [core.py:1093](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/core.py:1093), [core.py:1144](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/core.py:1144)

5. **Stored-source fallback uses Postgres.** It selects one `codebase_embeddings` chunk from the same project/file, prioritizing a matching declared symbol, then a definition chunk, then proximity to the indexed start line and chunk order. This is SQL selection, not vector search. It applies the character cap, but not the line cap or full-span option. Errors are swallowed, leaving the graph context without source. [core.py:1185](/Users/michaelmarler/Projects/rest_proxy/tools/brain/code_intel/core.py:1185)

**Uncertainty:** This is static source analysis only. Index freshness, edge completeness, and runtime availability were not verified. Local previews trust indexed line numbers, and stored previews may contain surrounding chunk content rather than exactly the symbol. The graph query also limits results without ordering before Python ranking, so selection is only over the returned subset.
